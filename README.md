# सफ़रनामा — Old Songs Playlist Website

यह एक single-page responsive music-library UI है जिसमें:
- Home / Trending / Playlists / Artists / Decades / Favorites
- Search
- Favorites
- Custom playlists
- YouTube URL से song add करना
- YouTube IFrame Player के जरिए playback
- Shuffle / Repeat / Previous / Next
- Browser localStorage में added songs, favorites और playlists save करना

## चलाने का तरीका
1. इस folder की सभी files एक ही जगह रखें।
2. `index.html` खोलें।
3. बेहतर अनुभव के लिए VS Code का Live Server या कोई local web server इस्तेमाल करें।
4. "＋ Add YouTube Song" दबाकर YouTube video का URL डालें।

## जरूरी बात
Demo में दिखाए गए कुछ पुराने songs placeholder entries हैं और उनके YouTube URLs वास्तविक playback के लिए भरे नहीं गए हैं। अपने अधिकार/अनुमति वाले YouTube links जोड़ें।

YouTube playback official embedded player के जरिए होता है; audio/video files को डाउनलोड करके इस साइट पर host नहीं किया जाता।
